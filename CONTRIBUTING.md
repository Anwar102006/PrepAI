# Contributing to PrepAI

First off, thank you for considering contributing to PrepAI! It's people like you that make PrepAI such a great platform for interview preparation.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct:

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please create an Issue and include:

- A clear and descriptive title.
- Steps to reproduce the bug.
- Expected behavior vs actual behavior.
- Any relevant logs or screenshots.

### Suggesting Enhancements

We welcome feature requests! Please create an Issue outlining:

- The problem the feature solves.
- A proposed solution.
- How it integrates with existing features.

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. Run `npm install` to install dependencies.
3. Make sure your code passes linting (`npm run lint`) and type checks (`npm run typecheck`).
4. If you've added new features, ensure they don't break existing tests.
5. Create a descriptive Pull Request detailing your changes.

## Development Setup

Please refer to the `INSTALLATION.md` for full instructions on configuring the PostgreSQL database, Upstash Redis, and OpenAI API keys required for local development.
